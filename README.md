# PIXEL WORLD 1.0 · 未知岛屿

一个基于 Three.js + Vite 的低多边形第三人称开放世界第一阶段原型。

## 当前版本包含

- 程序化低多边形岛屿地形、海洋、森林、岩石、云朵
- 营地小屋、古代信标、石拱门、篝火、宝箱
- 第三人称角色与跟随摄像机
- WASD 移动、Shift 奔跑、Space 跳跃
- 进入浅海区域后切换游泳状态
- 鼠标拖动旋转镜头、滚轮缩放
- E 键交互、帮助面板、小地图、任务 HUD

## 环境要求

- Windows 10/11
- Node.js 18 或更高版本（推荐 Node.js 20 LTS）
- VS Code

## 启动步骤

1. 解压项目文件夹 `PIXEL_WORLD`。
2. 使用 VS Code 打开该文件夹。
3. 在 VS Code 中打开终端：`终端 -> 新建终端`。
4. 执行：

   ```bash
   npm install
   ```

5. 安装完成后执行：

   ```bash
   npm run dev
   ```

6. 终端会显示本地地址，通常是：

   `http://localhost:5173/`

7. 按住鼠标左键拖动可以旋转镜头；滚轮可以缩放。

## 操作说明

| 按键 | 功能 |
|---|---|
| W / A / S / D | 移动 |
| Shift | 奔跑 |
| Space | 跳跃；水中短暂上浮 |
| E | 与附近物体交互 |
| 鼠标左键拖动 | 旋转第三人称镜头 |
| 鼠标滚轮 | 调整镜头远近 |
| H | 打开 / 关闭操作指南 |

## 构建生产版本

```bash
npm run build
```

构建结果位于 `dist/`。

## 说明

当前是第一阶段可玩原型。角色、地形、建筑和植被由程序几何体生成，不依赖外部模型文件。
游泳目前实现了进入水域后的移动状态、浮力位置和简化划水动画；后续阶段可继续加入水下镜头、潜水氧气、游泳碰撞和动画模型。
图像分割模型尚未接入；后续会在扫描仪玩法阶段加入真实模型推理接口。
